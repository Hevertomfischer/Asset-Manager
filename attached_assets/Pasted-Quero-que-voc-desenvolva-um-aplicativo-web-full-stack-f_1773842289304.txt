Quero que você desenvolva um aplicativo web full stack funcional chamado Cartola Intel, com foco em sugerir a melhor escalação para cada rodada do Cartola FC usando dados reais, sem dados mockados.

Objetivo da fase 1

Nesta fase, quero a primeira versão funcional de verdade, com:

frontend e backend rodando no Replit

PostgreSQL + Prisma configurados

coleta real de dados

armazenamento local no banco

dashboard funcional

listagem real de jogadores

projeções básicas reais

geração inicial de escalação automática

painel admin para sincronização manual

Não use mocks para jogadores, partidas, clubes, scouts ou projeções.
Só pode haver dados estruturais internos, como pesos, formações e configurações.

Regras de dados

Não usar nenhum dado mockado esportivo.

O sistema deve:

buscar dados reais

validar

normalizar

salvar snapshots

persistir no banco

exibir somente dados vindos das fontes reais

Se uma fonte falhar:

marcar a fonte como degradada no admin

Nunca inventar dados.
